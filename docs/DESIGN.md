# BillNest — Design System

## 1. Design Direction

BillNest should feel like a modern, trustworthy SaaS product.

The design should communicate:

- Organization
- Security
- Simplicity
- Reliability
- Modern technology

---

## 2. Color Direction

### Primary

Electric blue is the primary brand/action color.

Use it for:

- Primary buttons
- Active states
- Links
- Important highlights
- Brand iconography

### Customer Accent

Violet/purple is primarily used for customer-facing visual accents.

### Base

Use deep navy/black tones for dark mode.

Light mode should use clean neutral backgrounds while retaining the same blue/violet identity.

---

## 3. Typography

Preferred visual direction:

- Inter/SF Pro-like sans-serif
- Strong bold headings
- Compact labels
- Comfortable body text
- Clear contrast

Hierarchy:

```text
Hero heading
Section heading
Card heading
Body
Supporting text
Metadata
```

---

## 4. Components

### Buttons

Primary:

- Blue background
- White text
- Rounded corners
- Clear hover state

Secondary:

- Transparent/subtle background
- Border
- Contextual accent

### Cards

Cards should generally use:

- Rounded corners
- Thin border
- Subtle background contrast
- Small shadow/glow
- Consistent padding

---

## 5. Role Visual Language

### Shopkeeper

Use:

- Blue
- Store/business iconography
- Invoice/document visuals
- Business-oriented terminology

### Customer

Use:

- Violet
- User/shopping iconography
- Purchase/warranty visuals
- Consumer-oriented terminology

---

---

## 7. Responsive Design

Desktop:

- Wide two-column layouts
- Large hero typography
- Side-by-side role cards
- Four-column feature cards

Tablet:

- Reduced spacing
- Two-column cards where appropriate

Mobile:

- Single-column layout
- Stacked role cards
- Collapsed navigation
- Touch-friendly controls
- No horizontal overflow

---

## 8. Accessibility

- Maintain sufficient text/background contrast.
- Use semantic HTML.
- Buttons must be keyboard accessible.
- Interactive elements should have visible focus states.
- Do not communicate important information using color alone.
